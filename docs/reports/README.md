# Отчёты — Осман Асанов, М-И-25

Восемь отдельных отчётов Word по всем пунктам плана проекта Sunny Stickers. Каждый отчёт содержит три страницы: реализацию управления состоянием выбранным способом, методы работы с каталогом и количеством, методы корзины, избранного и темы. Код на рисунках взят из выполненного проекта, пояснения соответствуют реализации.

Оформление воспроизводит предоставленный образец: A4, Times New Roman, поля и абзацные отступы, подписи к трём рисункам. Все 24 страницы проверены после рендеринга. Автор — **Осман Асанов**, группа — **М-И-25**.
